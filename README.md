# Picklearo - Homemade Pickles Store & Landing Page

Welcome to **Picklearo**, an authentic homemade pickle storefront crafted for traditional, organic, and FSSAI-certified pickles from Muttipalam, Manjeri.

## 🚀 How to Open and Run

### Option 1: Direct in Browser
Double-click or open [index.html](file:///c:/Users/USER/Desktop/vs%20works/picklearo/index.html) (or [picklearo_homemade_pickles_premium_landing_page.html](file:///c:/Users/USER/Desktop/vs%20works/picklearo/picklearo_homemade_pickles_premium_landing_page.html)) in any web browser (Chrome, Edge, Firefox).

### Option 2: Run Local Dev Server
Run the built-in zero-dependency server:
```bash
npm start
```
Then visit:
👉 **http://localhost:3000**

## ✨ Features
- **Phone & Desktop Viewport Switcher**: Toggle easily between an interactive smartphone mockup view and full-width desktop view.
- **Product Catalog**:
  - Nadan Mango Pickle
  - Tender Mango (Kannan Manga)
  - Garlic Pickle (Poondu)
  - Beef Roast Pickle
  - Prawns (Chemmeen) Pickle
  - Lemon Pickle (Naranga)
- **Dynamic Size & Quantity Controls**: Select weights (250g, 500g, 1kg) and adjust quantity with real-time price calculations.
- **Direct WhatsApp Ordering**: Automatically formats and sends your selected items, weight, quantity, and total price to WhatsApp (`+91 9074613342`).
- **Category Filter Tabs**: Easily switch between All, Veg, Non-Veg, and Specialty pickles.
- **FSSAI & Heritage Badges**: Verified trust badges, Google Maps location link to Muttipalam, Manjeri, and customer reviews.
